DRAFTLY – Blogging Platform

DRAFTLY is a responsive blogging platform designed to provide a space for writers to create, publish, and explore articles.

Features

* Responsive homepage with article discovery.
* Article search and category filtering.
* User registration and login.
* Password confirmation and validation.
* Personal dashboard.
* Article creation and publishing.
* Article deletion.
* Live word counter.
* Article reading modal.

Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Right-click index.html.
5. Select Open with Live Server.

Note

This project currently uses browser Local Storage for demonstration purposes. Backend integration and database connectivity are not included in this version.
